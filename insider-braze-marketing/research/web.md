### 자료 8: Insider One Academy — Architect Terms to Know
- 출처: https://academy.insiderone.com/docs/architect-terms-to-know.md
- 저자·날짜: Insider One Academy, 2025-11-14
- 신뢰성: 최상
- 핵심 주장(요약 정의 — 용어집 장에 그대로 활용 가능):
  - Trigger(=Starter): 여정의 첫 단계, 조건에 맞는 사용자를 진입시킴
  - Element: 흐름 위의 노드(채널, 체크포인트, starter 등)
  - Condition(criteria): 사용자를 진입시키거나 여정 안에서 걸러내는 속성·이벤트·세그먼트
  - Path: 체크 조건·도달성 체크·A/B split 이후 갈라지는 가지
  - Live Actions: 보낸 메시지에 사용자가 특정 행동을 할 때까지 붙잡아 두는 대기 지점
  - Layer: 여정 안에서 사용자 상호작용 횟수, 두 번째 메시지 효과 확인
  - Conversion Goal / Conversion Attribution Model(예: 마지막 클릭 채널에 전량 귀속)
  - Dry Run: 실제 발송 없이 진입 인원·흐름을 시뮬레이션
  - Sunset: 신규 진입은 막고 기존 사용자는 계속 진행시키는 상태
  - Promotional vs Transactional Use Case: 프로모션은 opt-in 필요, 트랜잭션(주문 확인·비밀번호 재설정)은 opt-in 불요
  - 흥미로운 점: Insider도 여정 설계 화면을 "Canvas"라 부름 → Braze Canvas와 혼동 주의(용어 표기 박스 후보)
- 관련 섹션: 용어 정리, Architect vs Canvas 비교

### 자료 10: Insider One Academy — Liquid Tags (Insider의 템플릿 문법)
- 출처: https://academy.insiderone.com/docs/liquid-tags.md , 관련: https://academy.insiderone.com/docs/liquid-in-web-templates.md
- 저자·날짜: Insider One Academy, 2026-10-20
- 신뢰성: 최상
- 핵심 주장: Insider One도 Liquid를 지원하지만 **얼리 액세스**(Insider One 팀에 문의해 참여). 지원 채널: App Push(standalone), Web Push, Enhanced Templates, Web Templates, Email, Transactional Email API v2, Architect 여정 내 Email·Enhanced Templates. 문법: 출력 `{{ }}`, 로직 `{% %}`, 필터 `|`.
- 인용 가능한 구절(코드):
  > `{{ price | times: 100 | round }}`
  > `{%- if condition -%}` ... `{%- endif -%}`

- 비고: 기존(레거시) 개인화는 Dynamic Content 기능 — 이벤트·이벤트 파라미터·속성으로 콘텐츠 개인화. 레거시 태그 형식(`{{ attribute | default }}` 류)은 문서 표현이 불일치 — 본문에서 확정 문법으로 쓰지 말 것. Liquid 태그 빌더 목록에는 PII가 나오지 않는다는 제약도 있음(스니펫).
