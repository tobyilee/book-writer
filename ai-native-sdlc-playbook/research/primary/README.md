# Primary material — Claude Academy course "The AI-native SDLC playbook"

Captured 2026-10-19 from https://academy.claude.com/courses/ai-native-sdlc-playbook (public, no login required).
Files `00`~`15` are the 14 lessons plus the course home and completion page, in course order.
`99_claude-com-blog.md` is the claude.com article mirror of the same playbook (author: Louis Claxton, published 2026-08-21).

Each lesson follows one template: What changes (Traditional vs AI-native) · Getting started · How to execute it · What it looks like · Governance considerations · How to measure it (leading / lagging indicators).

Course structure: Introduction → Stage 1 Plan (intent.md) → Stage 2 Design (requirements and design) → Stage 3 Build (plan mode · CLAUDE.md · skills · parallel sessions and subagents) → Stage 4 Test (feedback loop · continuous evals in CI) → Stage 5 Deploy (AI in PR review · hooks as approval gates · CI/CD integration) → Stage 6 Maintain (closing the loop on metrics) → Closing.

The course's stated audience is engineering / platform / security leads at organizations already using Claude Code. The book adapts it for individual developers and small teams who already use Claude Code day to day.
