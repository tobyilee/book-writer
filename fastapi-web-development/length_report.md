# 분량 리포트 (length_report.md)

**측정 기준(정본):** 코드 블록 제외 · 공백 제외 · **각주 정의 줄 포함** · **수평선(`---`) 제외**

```bash
awk '/^```/{f=!f;next} !f && $0 != "---"' FILE | tr -d '[:space:]' | wc -m
```

기준을 두 번 명문화한 이유가 있다.

- **각주 정의 줄 포함** — 9장이 각주를 「장치이지 산문이 아니다」라며 제외해 세는 바람에 실측(11,132)과 자기 보고(8,710)가 어긋났다. 다른 장은 포함해 세고 있었다. 여러 에이전트가 같은 지표를 각자 재는 구조에서는 공식만이 아니라 **경계 사례까지** 못 박아야 한다.
- **수평선 제외** — 통합 단계에서 `---` 규약을 14장 전체에 통일했다(1·3·10장에 삽입). 수평선은 조판 마크업이지 산문이 아니며, 코드 펜스 줄을 이미 제외하는 것과 같은 원리다.
