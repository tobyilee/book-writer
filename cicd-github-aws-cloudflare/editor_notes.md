## 적용한 수정 (지시받은 교차 장 이슈)

1. **12장 오프닝:** HTML 편집자 주석 삭제. 세 질문을 1장 최종본 문구 그대로 옮기고, 답 문단을 새 질문에 맞게 고침(1번: 필수 체크+머지 큐+`make ci` 재현+플레이키 격리, 3번: 필수 체크 목록이 11장 PR 규약 파일에 있음 + 검사를 끌 수 있는 경로가 워크플로 파일(CODEOWNERS)과 브랜치 보호 규칙(관리자 권한자 명시)). 12장의 `make test` 5곳을 2장 정전인 `make ci`로 통일.
2. **OIDC immutable `sub`:** 이름 기반 `repo:ticketbox-org/ticketbox:...` 예시는 4장(설명 본체)과 6장(이미 4장 프레이밍 괄호 있음)에만 있다. 9·12장에는 `sub` 리터럴 예시가 없음을 확인. 12장 "다음 걸음"의 OIDC 교체 문장에 2026-07-15 이후 저장소 형식 주의를 추가하고, 신선도 감시 표에 immutable `sub` 행을 추가(4장 팩트체크 정정 내용 그대로, "나머지 다섯 줄"→"여섯 줄"). 저장소명은 전 장 `ticketbox-org/ticketbox`로 일치. 2장 CODEOWNERS의 팀 핸들 `@ticketbox/platform`을 조직명에 맞춰 `@ticketbox-org/platform`으로 통일.
3. **Cloudflare 프리뷰·버전:** 7·8장 외에 옛 주장이 남은 곳은 12장 두 군데였다 — "Worker Previews가 격리된 환경을 띄운다" → "`previews` 설정으로 묶은 스테이징 D1을 바라보는 프리뷰", "데이터와 바인딩과 시크릿은 되돌아오지 않는다" → "데이터와 스키마, 이미 일어난 외부 부작용". 신선도 표의 Worker Previews 행에 격리 범위(Durable Objects만 자동, D1·KV·R2는 `previews` 설정)를 명시. 9장의 Worker Previews 언급은 URL만 다뤄 문제없음.
4. **P-47(Qodo):** 인용은 11장 한 곳뿐이고 이미 정정된 문구. 다른 장에 "Beko"·"22개 저장소" 없음. 참고문헌 항목은 원장의 서지(Cihan 등, ICSE 2025 SEIP, arXiv:2412.18531)만 옮겼고 기업명·수치는 넣지 않았다.
5. **에이전트 결과 전달:** 9장은 "잡 출력·아티팩트"(그림)·잡 출력(코드), 10장은 "아티팩트로 남기기만" + 코드는 잡 출력이었다. 10장 문장을 "잡 출력이나 아티팩트로 넘기기만"으로 맞춤.
6. **`### 이 장의 핵심` 위치:** 4·5·6·7·9장 모두 클로징 절 직전. 10장만 장 맨 끝에 있어, 클로징 절("ticketbox의 신뢰 경계 그리기") 앞으로 옮겼다.
